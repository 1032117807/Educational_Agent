# Workflow

Keep a human confirmation point before every state-changing workflow step. Knowledge
point and question drafts remain drafts until reviewed. Reports must name their data
range and should not claim results not present in local learning records.

## How to use

Use this Skill for the durable flow: analyze resources, extract knowledge drafts,
generate questions, complete practice, then generate a report. Confirm each draft
or workflow step in the conversation before proceeding.
